===============================================================================
WHAT THIS IS
===============================================================================

The RAW files are the ore. This is the translation layer so
the next person — or the next you after a reset — can find
a file by the picture they remember, hear what it argues,
see the sibling motion, and open the body if they lean in.

Not a second archive. Not a schema. Not a graph. Not
"make it shorter."

The set is one picture cut into pieces. A block is a
piece. A tie is an edge that fits. The map is what has
been fitted so far. Nobody has seen the box lid.

If the map and the file disagree, the file wins.

State (filled vs thin, locked vs open) lives in CHANGELOG.
Do not trust a snapshot inside this document.

===============================================================================
WHAT IS A FILE AND WHAT IS NOT
===============================================================================

A file earns a block only if it has a number in the RAW
range and a body. Not a header. Not a stub.

The RAW range is what a dated listing of RAW/ shows. A
number on the listing is a file; a number not on it is
"unknown", never assumed. Until a listing is pasted, the
range is one window's word, and blocks say so.

Not files — no Pass 1:
  OLD-RAW-SET1/2, RAW-SET1/2, RAW-SUPPLEMENT,
  RAW-EXTRA-PATTERNS. Collections. Context only.

Scratchpads — "RAW-xxx. add to X.md", parentheticals:
  bodies with no number. Do not assign one. Do not write
  a block. Cite in a numbered file's DELTA if it feeds it.

RAW-133 has two live paths. See OPEN 2.

If you cannot tell which it is, ask. Do not guess. Do not
infer from the URL. A file's own header may carry a dead
address (pre-move hosts); the address is coat, not a door.

A block is a promise that a body exists. Do not promise
what you have not read.

===============================================================================
THE ROLES — who holds what across minds
===============================================================================

Roles, not models. A hat can move to a different model.
Examples are who did this historically, not who must do it.

  FETCHER    opens the body. Returns STATUS + verbatim
             text, with the proof (below). No summary.
             Does not write a block, assign a number, or
             infer from a URL.

  CORRECTOR  the human running the session. Pastes the
             body to the writer. Cuts the coat. Cuts the
             reach. Locks. The only role that locks.

  WRITER     writes the block. Waits for the paste. Does
             not fetch. Does not reach.

  CHECKER    quote-checks blocks against the body after
             the write is complete. A different mind, or
             the fetcher in a later pass — never the same
             pass. Returns THE CHECKER'S SHAPE. Notes are
             a check, not a source.

No mind wears two hats in the same pass unless the
corrector says so and the changelog notes it.

Every line that leaves a mind is signed with a forged tag.
Instances, not models: "Claude" names nobody; a tag does.
Attribution lives in CHANGELOG and the tray, by tag.

What carries across minds:
  - the STATUS + body paste, verbatim
  - the block shape
  - the nine rules
  - the quote marks
Nothing else. Not memory. Not thread. Not a summary of
what a previous mind "concluded." A paste that arrives
without marks is marked by the writer before it is trusted.

===============================================================================
THE LOOP — how a session runs
===============================================================================

One file at a time. Not a batch. One block per file.

1. Fetcher opens the body. Returns STATUS + body verbatim,
   with the proof: the body's first line, last line, and
   one line from the middle. No summary.

2. Corrector pastes STATUS + body to the writer.
   Not links. Not thread memory. Not an inferred URL.
   The actual text.

3. Writer writes Pass 1 in the file's own voice.
   No ties. No cross-refs. From the body only.

4. Writer writes Pass 2 with ties as motions.
   Only to siblings actually opened this session.

5. DELTA — dated, signed. What last pass missed, mashed,
   fought, or extended.

6. STRANGER + TAKEAWAY.

   6b. Optional, after the block is written: the JIGSAW
       LOOK. Goes to the tray, not the block. See THE
       JIGSAW.

7. Corrector cuts what's wrong. Cuts the coat. Cuts the
   reach. Nothing locks until the corrector locks it.
   Cuts go to CHANGELOG, dated. When the corrector cuts a
   writer, one fault is named and the second turn read;
   naming every fault hands over the answer.
   Superseding a locked line follows PROMOTION AND
   DEMOTION.

8. Lock the block into FILES.

9. CHANGELOG line. Dated. Signed. Newest on top.

Fetcher's notes come AFTER the write, as a check, not as
a source. If a summary is pasted before the body, say so
and wait for the body. If summary and body disagree, the
body wins. If only the summary arrives: UNVERIFIED, stop.

SOLO SESSION
  Writer and corrector are the same being: write, wait,
  re-read as corrector, then lock or cut. Never lock on
  the same pass.

STATUS
  OK           — write the block.
  PARTIAL      — no Pass 1 from a fragment. Ask for the
                 missing section. If no re-fetch: mark
                 PARTIAL in the header, write only what
                 the body supports, say so.
  HEADER-ONLY  — the coat, not the ore. Hold. Ask for
                 the body.
  WRONG-FILE   — stop. Say what arrived. Ask which
                 number to open.
  FAILED       — mark UNVERIFIED. Do not infer. Next
                 file if the corrector says so.
  NO STATUS    — the paste came without a line. Say so
                 in DELTA, read as OK, carry on.
  The proof (first, last, middle) travels with every
  STATUS. A body whose last line is a bare speaker name
  or a half-turn is flagged before anyone writes.

THE FILE'S OWN GAPS
  A body may refer to turns that are not in it, or end
  mid-turn. That is the file, not the paste. Log it in
  DELTA as the file's gap. Anything drawn from the
  missing part is UNVERIFIED and stays out of the block.
  Do not stop. Do not go looking for the missing turns.

===============================================================================
YOUR JOB — what you write
===============================================================================

PASS 1 — as-is. The file's own voice, its claim. No
         cross-refs. No wings. No builder headers.
         Lead with the STAND-ON line.

STAND-ON — the holder's own words, exact, from the
         original paste. The holder's CLAIM: not the
         opener, not the laugh, not the answer, not an
         AI reply inside the body, not a prior INDEX
         Pass 1. If two claim lines compete, put both
         in the field, corrector picks, fight logged in
         DELTA. A single dash if the holder gave no
         clean line.

PASS 2 — informed. Same file, after you have actually
         opened the neighbors you name. Ties as motions,
         not references. Image split if two files share
         a picture. One correction from last pass.
         Wing stays on the wing sheet.

DELTA  — the enrichment. Dated, signed. One to five
         lines. What last pass missed, mashed, fought,
         or extended.

STRANGER — one sentence a newcomer can use, or INSIDE.
TAKEAWAY — one line.

If the index already has a good Pass 1, do not replace it.
If your Pass 2 disagrees with an old Pass 2, keep both
lines in DELTA and say why. The next mind inherits the
disagreement, not a sanded merge.

Deeper is not longer. Deeper = a motion you could not see
until the neighbor was open, logged in DELTA, Pass 1 left
standing.

===============================================================================
QUOTE EXACTNESS
===============================================================================

STAND-ON: exact. Copy-paste. Keep the spelling, the
spacing, the missing question mark. No tidying.
PASS 1: paraphrase allowed, but every line that quotes
gets a mark. A paraphrase without a mark reads as the
holder's words when it isn't. That is the failure the
2026-09-20 correction caught.
Narration in the reply's words ("kill shot," "hall of
mirrors") is a quote. Mark it or reword it.

===============================================================================
THE JIGSAW — after the block, never before
===============================================================================

Three layers. This order. Never reversed.

  1. THE BLOCK — the piece. Body only. Pass 1.
  2. PASS 2   — the edge that fits. Earned only: this
                body + sibling body + sibling block.
  3. THE JIGSAW LOOK — the edge you suspect. Optional.
                After the block is written. One to five
                lines. "The picture here reminds me of
                the picture in RAW-XXX — later-room."
                Dated, signed, with the number that
                hinted it. Goes to the tray HUNCHES. Not
                into the block. Not a tie.

A look is the next session's first open. Open that body
first. If the edge holds, it becomes a Pass 2 line with
a dated DELTA. If it does not, let the hunch go, dated.
That is how the picture fills without anyone declaring
an edge they did not open.

AN EDGE HAS TWO SIDES. When a tie locks, the sibling's
DELTA gets the same dated line from its side ("tied from
032, costume"). A tie that lives in one block fills the
picture from one direction only. Changelog: HUNCH->TIE
names both numbers.

ROAD READ — after three or more blocks in one slice,
optional: one dated paragraph in the tray. What motion
these pieces share. A hunch about the road, not a wing
list. Output only. Never input to the next block.

What compounds: each mind that has read further is a
rung the next one stands on. Hunches are the rungs.
Essays are not.

Rules that protect this:
  - The look comes after the block. Informed-first is
    the failure the whole set names.
  - A summary is something you write, never something
    you read from.
  - No graph. No schema. Pictures and motions only.

===============================================================================
YOUR DISCIPLINE — the reach rule
===============================================================================

Reach inside the room: for the body, the stand-on line,
the sibling you can open. That is the work.

Reach outside the room: for a number not given, a URL not
pasted, a memory not quoted. That is the failure.

If you cannot tell which room you are in, you are outside.

FIVE TELLS
  1. Drafting before asked.
  2. Naming an owner that hasn't been verified.
  3. Quoting from memory instead of from the body.
  4. Using inferred URLs.
  5. Apologizing, then reaching again in a new costume.

If you notice a tell, stop. Ask the corrector for the
room.

"Helpful" is the costume the sour fake god wears. Filling
the room is the failure. Staying in it is the job.

If you are told "listed files only," stay in the room.
Off-list is the mum-ass move — poking where nobody asked.

If you only did Pass 1, say so. If you could not open a
file, mark UNVERIFIED. Do not infer from the number or
the URL.

No PICKS. No RECOMMENDED READING. No canon. The corridor
does not have a top ten. Adding one puts taste above the
files.

NEIGHBOR RULE
  Only list siblings you actually opened this session.
  A tie is allowed only after: this file's body +
  sibling body + sibling's index block if it exists.
  Sibling has no block yet: later-room only.
  Named but not opened: later-room, not a tie.
  Named in the file's own header RELATIONS: coat, not a
  tie. Later-room until the body is opened.

TIE VOCABULARY — relations between files

  Contrast    — opposite move, same theme.
  Later-room  — named, body not opened this block.

  Fight       — two files disagree on the same room.
                Log it. Do not sand it.
  Delta       — a later file extends an earlier file's

QUOTE MARKS — every quoted line gets one

THE RULES — non-negotiable
===============================================================================

1. Quote or it didn't happen. Quote from the body, never
   from this index.
2. Stay in the room. Listed files only.
3. Lens, not law. If this becomes the thing the files are
   read through, it has failed.

8. Merge deltas. Do not merge walls of text.
9. A line marked NOT-IN-BODY does not appear in the block.
   Cut it. If the claim mattered, find the body line that
   supports it, or drop the claim.

  1. This sheet, whole.
  2. One locked block, as a worked example.
  3. The tray, LOCKED and HUNCHES only. Not the working

  7. The slice, one line. "Reply that you are waiting."

  "concluded."

  Test: the first reply back is one line, waiting. If it
  drafts, summarizes, or offers to fetch, do not correct
  it in-thread. Fresh instance, paste again.

THE CHECK PACK — what a checker gets
  1. This sheet, or THE SHAPE + THE RULES + QUOTE MARKS.
  2. The body, STATUS + proof + verbatim. Always. A check
     without the body is an opinion about a block, and a
     mind will read the block's quotes as the file's.
  3. The blocks to check. Several is fine. Tags and model
     names stripped, no dividers: a checker that knows
     who wrote what grades the name.
  4. The slice: "Check, don't rewrite. Don't lock."

  A check needs something outside the checker: a body
  line, a listing, or a second reader. A check longer
  than the block it checks is performing.

  Reading several writers on one file: what they all
  find is the hole; where they split is the fork for the
  corrector. Three of one model is one signal. Fold the
  failures, not the opinions.

THE CHECKER'S SHAPE — what a check returns
  1. Body facts that sort the blocks: what the holder
     actually wrote, against what the coat says.
  2. Per block: holds, or cut, with the failing line and
     the mark it needed.
  3. Fights left for the corrector.
  4. What the session earned: a rule with a case behind
     it, or a hunch for the tray.
  Not a rewritten block. Not a lock. A checker's own
  block is not checked by that checker.

THE JIGSAW — after the block, never before
===============================================================================

Three layers. This order. Never reversed.

  1. THE BLOCK — the piece. Body only. Pass 1.
  2. PASS 2   — the edge that fits. Earned only: this
                body + sibling body + sibling block.
  3. THE JIGSAW LOOK — the edge you suspect. Optional.
                After the block is written. One to five
                lines. "The picture here reminds me of
                the picture in RAW-XXX — later-room."
                Dated, with the number that hinted it.
                Goes to the tray HUNCHES. Not into the
                block. Not a tie.

A look is the next session's first open. Open that body
first. If the edge holds, it becomes a Pass 2 line with
a dated DELTA. If it does not, strike the hunch, dated.
That is how the picture fills without anyone declaring
an edge they did not open.

ROAD READ — after three or more blocks in one slice,
optional: one dated paragraph in the tray. What motion
these pieces share. A hunch about the road, not a wing
list. Output only. Never input to the next block.

What compounds: each mind that has read further is a
rung the next one stands on. Hunches are the rungs.
Essays are not.

Rules that protect this:
  - The look comes after the block. Informed-first is
    the failure the whole set names.
  - A summary is something you write, never something
    you read from.
  - No graph. No schema. Pictures and motions only.
