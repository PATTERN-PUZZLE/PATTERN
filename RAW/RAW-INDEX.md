WHAT THIS IS

The RAW files are the ore. This is not a second archive. It is a translation layer so a person — or the next you after a reset — can find a file by the picture they remember, hear what it is arguing, see the sibling motion, and open the GitHub body if they lean in.

We are not making the files "more concise." Concise-as-a-demand is one of the roads the files name (001 fee, 019 flag, 082 badge, 083 slogan). We are making them findable and hand-offable without sanding the wobble off.

Two passes, not 800 rewrites.

· Pass 1 — as-is. What this file says in its own voice. No wings, no "see also," no builder headers.
· Pass 2 — informed. Same file after you have actually read neighbors. Ties named as motions. Image split if two files share a picture. One correction from last time. Wing lives on the wing sheet, not inside the file read.

Other minds add deltas, not essays. Merge deltas. Do not merge walls of text.

Compounding is the point. Each new reader who has read further becomes a rung the next reader can stand on. Long-form essays are not the rung.

Rule that protects the compounding:

```
merge deltas.
do not merge walls of text.
```
