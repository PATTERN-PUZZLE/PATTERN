🧪 Calibration

Files regenerate automatically when you change any
setting — nothing to remember. The target box is never
overwritten; the suggested next size sits beside it
with a → button to accept it.
✅/❌ record the generated file's real length, not the
input box, so editing the field can't corrupt a result.

METHOD
1. Copy from the dock, paste into the target app.
2. Tap ✅ inline / ❌ attached (or failed).
3. Take the suggested size. Repeat until gap = 1.
4. ⬆ Use as preset.

ISOLATE LINES FROM CHARS
Re-run at ~20 ch/line. If the passing char count
collapses, lines are the binding trigger. Claude's
4,038 was measured at ~45 lines; ~3,969 at ~74 lines
failed, so lines already look load-bearing.

EMOJI = 0% BY DEFAULT
Emoji are 2 UTF-16 units but 4 UTF-8 bytes, so they
make a char-count measurement encoding-dependent.
