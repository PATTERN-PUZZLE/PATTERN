🟣 CLAUDE APP MESSAGE (Clean mode):
Goal: stay under the threshold where the app converts
a paste into a "pasted content" attachment.
3.9K — measured trigger point was ~3,969 chars
(~74 lines, ~585 words). Not officially documented —
user-measured only. Recalibrate with 🧪 Test if it drifts.
3.6K / 3.2K — step down if 3.9K still attaches.
Line cap matters: the trigger appears to be line-
sensitive too, so cap ~70 lines per chunk as well.

DEEPSEEK PASTE (Raw mode):
168K — high. Light files, few line breaks.
165.1K — mid. Works for most files.
163.7K — low. Safe default. Works for all.
STEP-DOWN: If chunk fails, reduce by 1K.

URL FETCH:
75K — GitHub #readme anchor.
65K — standard raw URL (Vercel, GitHub raw).
40K — universal (all platforms incl. Perplexity).

CLEAN vs RAW vs DEPLOY:
Clean = byte-for-byte source, zero added characters.
Raw = adds 🎳 n/N label + --- + CHUNK-ANCHOR.
Deploy = full .md files with nav headers.
Deploy reserves real measured header length per chunk.

ANCHORS:
CHUNK-ANCHOR verifies split delivery.
TH-CHECK (♦️) verifies original file integrity.
Different purposes. Both matter.

LINE DENSITY GUIDE:
Under 1,000 lines → try 168K or 165.1K.
1,000-3,000 lines → use 163.7K (safe).
Over 3,000 lines → use 131K or URL fetch.

WHY THIS MATTERS:
The paste limit depends on LINE COUNT,
not character count. STANDARDS.md has
3,460 lines and failed at 165K.

DENSITY:
Over 60 chars/line → safe for all presets.
Under 40 chars/line → use lower presets.
🧪 Calibration Testing Guide

Generates test files matching real ecology files.
Defaults: ~73 char lines + 10% emoji.
Numbered lines show running character count.

HOW TO CALIBRATE (paste limits):
1. Generate a test file at target size.
2. Paste into a FRESH instance.
3. Ask: "What is the exact last line?"
4. Binary search until exact limit found.
⚠️ Use FRESH instances for EACH test.

HOW TO CALIBRATE (Claude app attach):
1. Generate at 3,900. Paste into the message box.
2. Did it become an attachment? Yes → go lower.
3. No → go higher, 100 at a time.
4. Repeat with ~40 char lines to test line-count
sensitivity separately from char count.
