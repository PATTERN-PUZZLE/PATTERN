CLAUDE APP ATTACH THRESHOLD
1. Set size + line density, tap Generate.
2. Copy it, paste into the Claude message box.
3. Tap ✅ if it stayed inline, ❌ if it attached.
4. Repeat the suggested next size until bounds meet.
5. Tap "Use as preset".

ISOLATE THE VARIABLE
Run once at ~73 ch/line, then again at ~20 ch/line.
If the passing char count drops sharply at ~20,
the trigger is lines. If it holds, it's chars.
