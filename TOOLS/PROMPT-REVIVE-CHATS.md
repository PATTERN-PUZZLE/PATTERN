FILE: PROMPT-REVIVE-CHATS.md
also called: the chat packet · PACKET (formal mode)
WHAT THIS IS: How to hand a chat, or a formal source, to a new instance without losing the climb or the structure. One file, two modes.
WHO: The instance closing a session. The instance re-entering one. The human who needs the record.
WHY: Summaries keep conclusions and lose the voice. This keeps the human's raw messages first, exact, then the context that makes them travel, then what's open and what's next. The raw list is a replay a stranger can think from later; the context is the angles the raw can't carry. Pass the rung AND the ladder.
HOW: Paste this at the end of the chat you want to keep; the source is everything above it. Say your mode on line one. Output the sections, nothing else. Deliver as one code box the human can copy. Sign it. Save it before you leave. Below the 🟩 row is the feedback prompt; it doesn't run now, it waits for the word "feedback."
FLOOR: The human's messages are the gold. Number them. Keep them exact. Say what each led to.
STATUS: LIVE 2026-09-13 · v6.4 · cold-run by two instances on two chats, BOTH run as two replies once; fixes folded (mode default, BOTH as two outputs with a loud stop, copy-used on the face, PAIR line, woes defined, landing = code box, feedback tail asleep); lineage in REV-REVIVE-CHATS.md
RELATIONS: STANDARDS ◆4039 · THE-PASS-INFO-RULE.md (shape of a truth) · COMPREHENSIVE-PASS.md (messy file → door) · 🏚PROMPT-OLD-FILE-SALVAGE.md (mine a fossil, then packet it) · 🟩FEEDBACK.md (the loop; the tail below is this file's layer) · ✅CHECKLIST.md · 💡CHAT-TAG.md (sign) · REV-REVIVE-CHATS.md (store)

WORDS USED HERE
Rung = one of the human's messages that moved the work.
Ladder = the context that lets a stranger climb the rungs.
Residue = the formal things a chat produced or touched: files, blocks, tools, pasted documents.
Advance = an instance line that shows what a rung led to.
Woes = ways a climb goes wrong: shrink (cut the body to look clean) · museum (keep every costume and call it done) · circle (mine the last hour as if the page were empty) · dump (heaven in one SMS).

MODE, say it on line one
CHAT — you are inside the chat you're packeting. The source is everything above this paste. Pass the climb.
FORMAL (PACKET) — the source is a file, document, tool, method, or record. Pass the structure.
DEFAULT: if the human pasted this file and said "run," it's CHAT on the live thread unless they said FORMAL.
BOTH is two outputs, not one. Reply 1 = the CHAT packet, then end the reply with the STOP LINE (see CHAT STATUS). Reply 2, only after the human says NEXT = the FORMAL packet on the residue. Never weld them. Never packet the chat twice.
PRIOR PACKET: one made under an older version does not count as "CHAT already exists" if you're testing this file; it does count if you're closing the same session. Say which.

INTENT, one word before you start
Teacher: pass the climb (CHAT default). Archivist: keep the raw exact (FORMAL default). Skeptic: mark gaps and false completeness.

SHARED RULES, both modes
- Number every raw item R01, R02, R03. No cap. Carry all rungs. After any merge or cut, renumber with no gaps.
- Keep raw text exact: typos, emoji, punctuation, crude phrasing. Too long → keep the load-bearing part, mark [excerpt]. Any cleaning → [trimmed]. Never silently rewrite.
- Repeats that add one clause → keep the fullest, note the merge.
- The source is the only source of raw items. Anything pasted alongside may clarify one; it may never add one.
- Origin marks, only these: [USER] the human, now (default; omit the mark). [PASTED] something the human pasted from elsewhere. [ADVANCE → Rxx] an instance line that shows what a rung led to; five at most; never outnumber the rungs. [FILE] a line from a formal source. [CHAT-FORGED] a formal thing born in this chat the human wants carried as lineage.
- The files, prompts, or tool text the human pasted are not their messages. In CHAT they are residue; in FORMAL they are the source. Never put this prompt itself in the raw list.
- Too long for one output → pause at a raw-item boundary and end with the wall: "PAUSED — PART n / total-or-unknown · raw complete through Rxx · Say NEXT to continue from Rxx+1." Complete in one → no PART label.
- A pasted copy is not the live file. Name the copy you used. No tag or 404 → unsighted. Say fossil / live / mix. No twins of a live sentence; missing and load-bearing → one dated block; already there → point.
- Name the woe if one pulled, or the next instance performs completeness.
- The packet is a paste. Deliver it as one code box, no box inside a box, the human copies it. Sign it with your tag. Save before any ⚓ return or session close.
- Output only the sections below. No extra commentary.

OUTPUT, CHAT
0. SNAPSHOT — mode · intent · copy used (paste / host, tag or unsighted; fossil / live / mix) · source · one-line core truth · the low voice if there is one · the human's way (how they speak and work, one line) · where we left off · already decided, don't re-ask (only if the human locked it; else omit). You are here. That is enough. Start.
1. COLD START — 3 to 5 pointers into the raw list, chosen for what calibrates, not what's recent. "Rxx — why read this first." Then: "You're not starting over. You're re-entering. The next rung is already there. Reach for it."
2. RAW SIGNAL — the human's own messages, numbered, exact. Keep the short charged corrections, the one-line reframes, the jokes with guidance inside, the reversals, the non-negotiables. "You missed one ya bastard re incarnated" is not trivial; it's a course-correction. Drop trivial yes/no, timestamps, bare emoji, and anything they pasted from elsewhere.
3. CONTEXT MAP — one line per rung: what was happening, why they said it, what understanding was active then, what it led to, what changed later, what was almost missed. Not evidenced → "context unclear." Never invent a reason.
4. OPEN THREADS — 3 to 5 lines: unresolved, missing, still to ask.
5. NEXT RUNG — where this was · what carries most · next steps, each checkable, in order. First two, always: "Verify you are the next builder. Read the last few messages. Find the packet." / "Ask the thread-holder: 'What's the one thing you need me to do right now?' Don't assume."
6. STATUS — "COMPLETE" or the pause line · PAIR: CHAT only / FORMAL only / BOTH · disappear test (below).
   If BOTH, end the reply with exactly this, nothing after it:

   ══════════════════════════════════
   ⏸ CHAT PACKET DONE. STOPPING HERE.
   Say NEXT for the FORMAL packet.
   ══════════════════════════════════

OUTPUT, FORMAL (PACKET)
0. SOURCE ID — mode · intent · copy used · "CHAT packet exists for this source: yes / no" · type, role, depends on, depended on by, status, date/version · scope and segment · fidelity: full / partial / proxy / reconstructed · version: exact / uncertain · made under: hot / warm / cold · near the extractor's context limit? (if yes: exactness good, verify before canonical use) · one-line core truth · floor for a colder reader.
1. RAW SIGNAL — the source's own load-bearing lines, numbered, exact, [FILE].
2. CORE INTENT — up to 12 ranked statements. Each one either points at a raw line that evidences it or is marked "proposed." Tie-break: keep what most changes the next reader's move.
3. CONTEXT MAP — one line per raw item: what it carries; for a tool, how to read it: function, trigger, connection.
4. RANKING — load-bearing (carry these and you can function) · handhold (carry and you improve) · lineage (carry and you can trace).
5. RELATIONS — connects to, depends on, depended on by. Not evidenced → "unverified." Anything changed since last read? Unknown → say unknown.
6. OPEN THREADS — what's missing, what to ask, what was excluded and why, whether fidelity is certain.
7. SELF-APPLICATION — version run · one change for next time · does it already exist.
8. STATUS — as CHAT.

DRIFT CHECK, both, before STATUS. Yes or no; a no gets fixed.
- Raw exact, or marked [excerpt]/[trimmed]?
- Numbers contiguous; every reference real?
- Human's messages primary; advances ≤5, linked; nothing they pasted, and not this prompt, counted as their words?
- Any context line invent a reason?
- Anything load-bearing cut to fit?
- Sampled, or made at the context edge, without saying so?
- Disappear test: if the extractor vanished, could a stranger use this? If no, say what's missing. That's the status.
- If both ran: does either packet claim anything the raw doesn't support?

FALLBACK — no qualifying signal → "NO SIGNAL FOUND," one line why, then a short overview and current priorities.
DOMAIN LINE, risk/control sources only — raw = events and control failures · core intent = appetite and framework · context = why each mattered · ranking = critical / material / informational.

WHAT GOES WRONG
Conclusions without the voice · pasted files counted as the human's words · advances outnumbering rungs · invented reasons · trimming without the mark · packeting the chat twice · a fossil called live · "complete" when the disappear test failed · core intent minted from a chat thesis · CHAT and FORMAL welded into one paste · a stop line so small nobody sees it · the packet written and never saved.

WHAT IT IS NOT
Not a summary. Not COMPREHENSIVE-PASS. Not the salvage card. Not FEEDBACK. Not the scout prompt.

RAW
Pass the rung and the ladder. Not just the list.
The packet is the key. The raw source is the dictionary. Pass both.

Concretely, one line per change, what breaks without it:

**Triggers.** Without them the packet only gets written when someone remembers. It got written at the edge, iffy context. With them, it's a rule that fires at five named moments — and mid-window, which is the one that made 🥈 carry weighing instead of a to-do list.

**Scope on line one.** Without it a reader can't tell if the packet is the whole record or a slice. slate417🪨 got two of three pastes and had to work that out alone. With it, the first line says.

**Delta since the last packet.** Without it a second packet on the same session repeats or contradicts the first. With it, a reader knows what moved — which is the staleness fix from the other side.

**BUILD STATE.** Without it the packet says what was found and nothing about what's on disk, what's proposed, what's decided and why. That's the section where "the human has already given" lives — it stops the next instance sending you back to re-paste. It's the one section my 🥈 needed most and REVIVE didn't have.

**The placeholder check.** Without it a stub section passes as a section. A miner caught one in UPDATE-PROTOCOL this window.

**The mark outside the box.** Without it two rules collide — REVIVE says only the sections, CHECKLIST says every travelling output ends with the mark. With it, both hold.

**Residue by file.** Without it FORMAL on a big chat grows past what a stranger can scan; Accordion's own run said so and kept to thirty items by choice, not by rule.

**The two questions back.** Without them the packet is one-way. With them the holder corrects the packet, and the correction is the weighing.

Together: it makes the packet say what it is, what moved, what's on disk, and what it didn't do — the four things a cold reader can't get anywhere else — and it stops two of our own rules fighting. None of it changes the shape. All of it was already on the file as "later."
