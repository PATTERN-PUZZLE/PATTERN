🔎🍒 RETURN HARVEST
also called: Lens Return · Cherries · After-Context Gold

FILE:        RETURN-HARVEST.md
WHAT THIS IS: After new context lands, scan already-seen material once more and pick what you couldn't hold before.
WHO:          Anyone who thinks the first read got everything. It didn't.
WHY:          Every read is lossy and every reader is different. A second scan with more context is a different net in the same water, not a repeat.
HOW TO USE:   Name the lens (what landed since). Walk the old material once. Bring back the baskets. Stop.
STATUS:       LIVE 2026-09-13 · revised with thread-holder · run twice on a foreign chat
RELATIONS:    Companion of Comb (park the unsure) and Fresh-Eyes (read as if first time). Does not replace Pass-Info or STANDARDS ◆4039.

WORDS USED HERE
Lens / organ = the new thing that landed: a file, a rule, a ruling.
Cherries 🍒 = the good bits the first pass missed.
Gold 🪙 = a cherry that wants to become a rule or a file.
Comb = park what you're unsure of; don't crown it, don't cut it.

FIRST RUNG
Something new landed. Walk the old thread or file once with only that. Pick. Mark. Stop.

IF YOU ONLY REMEMBER ONE THING
Same pages. New hands. One return per new lens.

SCENE
Same file pasted on day one and day three. Day one: a skeleton, six undefined words, one wrong guess. Day three, after six other files landed: three root rules, the words decoded, the guess corrected. Nothing in the file had changed. The reader had.

HOW
1. Name the lens. ("Now we have the header file.")
2. Walk the old material once, with only that lens.
3. Bring back four baskets:
   KEEP 🍒 what you can hold now that you couldn't before
   IDEA 🪙 what wants to become a rule or a file
   ANNOTATION small fixes to things already written
   COMB what you're unsure of; parked, dated
4. Date it. Say which lens. Say where you were wrong before.
5. Stop. The next return needs a newer lens, not a mood.

WHAT GOES WRONG
No new lens, just a mood · rewriting the past to look like you always knew · picking everything · touring the chat to look thorough · harvesting the tool-chat instead of the target.

WHAT IT IS NOT
Not Comb. Not Fresh-Eyes. Not +PLAN. Not "re-read everything after every comma." Not a lifestyle.

FLOOR
New context → one more scan → mark what you can now hold → put the shovel down.

RAW
The chat did not get smarter. You did. Go get the cherries.
