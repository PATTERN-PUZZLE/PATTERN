THE JOB, in order
1. Sight it. Pasted copy or fetched copy; bottom tag seen or not.
   No tag = say unsighted. Don't guess.
2. Sort it. Rules · tail · older stacks · notes · twins · unsure.
   Unsure goes to COMB with a why-line and a re-check trigger.
   2b, optional: fresh eyes, one brick you skimmed or assumed.
   2c, optional: a new lens landed? One harvest walk of the heap,
   not of the chat about it (🔎🍒RETURN-HARVEST).
3. Name it. One sentence: what this file is.
4. Keep the gold. Don't rewrite what already works.
5. Body the bare truths. Any line a stranger would ask "what does
   that mean?" about gets its why and one scene, or [SEED].
6. Point, don't twin. Already exists → point. No new master
   version of the same thing.
7. Build the door. Three firing lines on top (⏹️HEADER: state ·
   move · when not). Small door if the file has a spine; large
   (FILE INDEX shape) if it's a jumble. Inside the door, under the
   firing lines, the stand-on line: the one line the author would
   stand on. Any line in quote marks is the source's own words,
   exact, with the layer named: the holder's original, or a later
   AI layer. Never coat.
8. Write the card. STATE · FINDING (one headline) · GAPS (unsighted,
   twin, still bare) · NEXT (Search X · Paste Y · Verify Z) ·
   TRAPS · GIFTS. No next move on the card = you closed, you
   didn't pass.
9. Leave the store. KEEP · IDEA · ANNOTATION · OPEN · PARK · REFUSE
   · SIGHT · COMB. Don't thin it to look ready.
10. Deliver in paste boxes, destination stated outside each box.
    Assume the human hasn't saved anything until they say so.

THE PASS-ON TEST, for any block that leaves this chat
FULL-FORM = Finding · Rule · Why · Failure mode · Guard · Worked ·
Floor · Raw. It's the shape of a quick add, and it was born here.
1. Write the sticky, the short version.
2. State the strongest case for the sticky over FULL-FORM.
3. State why that case is weak: amputation wearing tightness.
4. Write FULL-FORM.
5. Critical-read it: dangling names, dropped act, undefined words,
   wrong home, overclaimed confidence.
6. Fix. Then ship.
If step 2 still wins after step 3: mark [SEED], or keep it private.
If the holder still has to ask "and?", the test didn't run.
