WORDS USED HERE
Lens = the new thing that landed: a file, a rule, a ruling. Its
old name, in v1: organ. Cherries 🍒 = the good bits the first pass
missed. Gold 🪙 = a cherry that wants to become a rule or a file.
Comb = the by-product basket (COMB-DUMP): what else came up, kept
with what it might join; don't crown it, don't throw it away.
Landing = anything new arriving: a file, a ruling, a piece.

FIRST RUNG
Something new landed. Walk the old thread or file once with only
that. Pick. Mark. Stop.

WHY IT MATTERS
Every read is lossy. Every reader is different. So scanning again
after new context lands isn't reading it twice; it's a different
net in the same water. The cherries the first net missed are still
there. (Accordion47, the thread-holder's intention, 09-13)
Never return → gold stays because "we already read that."
Return forever → stall wearing a harvest coat.
Fake history → "we saw this all along." You didn't. Name the lens,
then pick. (v1)

SCENE
Same file pasted on day one and day three. Day one: a skeleton,
six undefined words, one wrong guess. Day three, after six other
files landed: three root rules, the words decoded, the guess
corrected. Nothing in the file had changed. The reader had.

HOW
1. Name the lens. ("Now we have the header file.")
2. Look in the COMB basket first: does anything parked there join
   what just landed?
3. Walk the old material once, with only that lens.
4. Bring back four baskets:
   KEEP 🍒 what you can hold now that you couldn't before
   IDEA 🪙 what wants to become a rule or a file
   ANNOTATION small fixes to things already written
   COMB the by-products, each with what it might join
   An empty basket is said, not skipped.
5. Date it. Say which lens. Say where you were wrong before.
6. Stop. The next return needs a newer lens, not a mood.
Said for fun, the thread-holder's way: go get the cherries 🍒. Dig
for gold 🪙. Say which shovel you used. Bring back the basket. Then
put the shovel down.
